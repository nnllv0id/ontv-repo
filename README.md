# OnTV — Kodi Addon

> 🇵🇹 Português | 🇬🇧 English

---

## 🇵🇹 Português

Addon IPTV para Kodi 21+ com suporte a portais Stalker/MAC e Xtream Codes.

### Instalação

**Método 1 — Repositório (Recomendado)**

1. No Kodi vai a **Definições → Gestor de ficheiros → Adicionar fonte**
2. Insere o URL: `https://nnllv0id.github.io/ontv-repo/` e dá o nome **ontv-repo**
3. Vai a **Add-ons → Instalar a partir do ficheiro zip → ontv-repo**
4. Selecciona `repository.ontv/repository.ontv-1.0.2.zip`
5. Instala o **OnTV** em **Instalar a partir do repositório → OnTV Repository → Video add-ons**

**Método 2 — Download directo**

1. Descarrega o ficheiro [repository.ontv-1.0.2.zip](https://nnllv0id.github.io/ontv-repo/repository.ontv/repository.ontv-1.0.2.zip)
2. No Kodi vai a **Add-ons → Instalar a partir do ficheiro zip** e selecciona o ficheiro
3. Instala o **OnTV** em **Instalar a partir do repositório → OnTV Repository → Video add-ons**

## 🇬🇧 English

IPTV addon for Kodi 21+ with support for Stalker/MAC portals and Xtream Codes.

### Installation

**Method 1 — Repository (Recommended)**

1. In Kodi go to **Settings → File Manager → Add source**
2. Enter the URL: `https://nnllv0id.github.io/ontv-repo/` and name it **ontv-repo**
3. Go to **Add-ons → Install from zip file → ontv-repo**
4. Select `repository.ontv/repository.ontv-1.0.2.zip`
5. Install **OnTV** from **Install from repository → OnTV Repository → Video add-ons**

**Method 2 — Direct download**

1. Download [repository.ontv-1.0.2.zip](https://nnllv0id.github.io/ontv-repo/repository.ontv/repository.ontv-1.0.2.zip)
2. In Kodi go to **Add-ons → Install from zip file** and select the file
3. Install **OnTV** from **Install from repository → OnTV Repository → Video add-ons**
