OnTV

Repositório oficial OnTV para Kodi

Método 1 — File Manager (Recomendado)
https://nnllv0id.github.io/ontv-repo/
1
No Kodi vai a Definições → Gestor de ficheiros → Adicionar fonte
2
Clica em <Nenhum> e insere o URL: https://nnllv0id.github.io/ontv-repo/
3
Dá o nome ontv-repo à fonte e confirma
4
Vai a Add-ons → Instalar a partir do ficheiro zip → ontv-repo e seleciona o repository.ontv-1.0.1.zip
5
Por fim instala o OnTV em Instalar a partir do repositório → OnTV Repository → Video add-ons
